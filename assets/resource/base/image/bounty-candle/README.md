# 守卫宝烛原生识别素材

本目录只保留仍被 Pipeline 使用的暂停提示、登录和已有存档模板，采用本工程短边 720 坐标。进关、场景确认和返回确认复用同目录外已有的 `任务.png`、`守卫宝烛场景.png` 及 `设置.png`。

入口使用“任务 → 悬赏任务 → 前往副本”。目标名称与按钮在同一任务详情画面内组合核对，不再使用须弥山入口、旧悬赏榜卡片或世界/洲地图导航素材。存档槽位还须正向识别等级标签，不能点击“新建角色存档”的空槽。

运行、构建和测试不依赖原工程、私有任务包或迁移目录，也不附带另一套 OCR 模型。旧界面截图仅在 tests/fixtures 中作为离线回归资料保留。
