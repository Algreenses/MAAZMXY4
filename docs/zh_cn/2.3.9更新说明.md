# 2.3.9 更新与升级说明

本版在 2.3.8 的原生脚本工作台和统一更新器基础上，增加游戏数据库、游戏管理，并细化导航与浮窗处理。

## 更新内容

- 新增侧栏游戏数据库，离线查询电脑版装备、道具、Boss 的属性、获取方式和技能；展示官方、社区和客户端配置来源，对缺失或冲突字段保留说明。
- 扩展关卡普通、首次可进入、悬停状态及常见浮窗识别；确认覆盖层后减少底层重复探测，图标暂时缺失时使用 Maa 原生只读等待。可移动地图保持按当帧识别框操作。
- 还魂丹窗口按身份、尺寸和单人/双人布局确认后，使用窗口内偏移点击取消，避开小字与倒计时差分。等待覆盖 10 秒倒计时及结算过渡；确认失败并返回地图后才重试。
- 新增可选的失败恢复、内存维护和按分钟间隔重启。刷关维护在本轮结束后执行；答题等待整局结束，异常中断保留日志并停止，避免消耗次数。
- 减少任务配置解析、隐藏实时画面及空闲装饰动画的开销，保留原有 Maa 控制器、输入和任务队列。

## 升级方法

本版有定制前端变更，**2.3.8 及更早客户端请安装完整包**。资源 ZIP 的最低客户端版本为 2.3.9，不用于跨越前端版本升级。

1. 停止任务和录制，保存编辑内容并关闭助手，先备份旧目录。
2. 将完整 EXE 或 ZIP 安装/解压到新的空目录。
3. 如需迁移已有数据，在新旧助手都关闭时，复制旧目录的 `recordings/`、`config/`、`appsettings.json`（存在时）到新目录；不要复制旧程序或资源覆盖新版。
4. 运行新目录的 `MAA造梦西游4.exe`，检查窗口选择、脚本绑定、次数及返回方式后再开始任务。

完整包只附带脚本格式示例，没有个人录制或默认任务绑定。未绑定任务会提示并停止。各发布仓库的更新源相互独立：fork 包使用 fork 的清单，不能把安装 fork 版本等同于上游已经发布。
