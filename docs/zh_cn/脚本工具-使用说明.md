# 脚本工具：录制、脚本库与时间轴编辑

“脚本工具”是 MFAAvalonia 内的原生页面，沿用现有侧栏和主题，包含两个子标签：

- **脚本库与录制**：查找、导入、导出脚本，选择游戏窗口并录制，指定任务回放文件。
- **时间轴与编辑**：查看键鼠轨道和操作列表，修改操作、添加点击与阶段标记、撤销重做、检查及拆分。

已有 `recordings/*.json` 可直接打开。也支持导入 ZaoMengScript 的 `zaomeng.macro` v1 录制；导入时转换时间单位和720基准坐标，保存后生成本项目格式，不修改源文件。

## 使用前端

仓库不包含 MFAAvalonia 客户端源码和二进制。新增页面以固定上游源码补丁与页面源文件维护，需构建后使用：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/build_frontend.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File tools/preview_frontend.ps1 -Launch
```

需要 .NET 10 SDK 和本项目已安装的内嵌 Python。预览目录是 `dist/script-studio`，使用独立配置与脚本库。`-Demo` 可加入一份只供编辑练习的示例，它不是实际副本策略。

如需替换本机原前端，先关闭原前端，再运行 `tools/build_frontend.ps1 -Install`。安装前会备份文件。构建与恢复说明见 [前端说明](../../frontend/README.md)。

## 录制

1. 启动造梦盒子，进入希望录制的战斗起点。
2. 打开“脚本库与录制”，刷新并选择游戏窗口，设置倒计时。
3. 点击“开始录制”，切回游戏操作。当前任务必须已停止。
4. **F8** 暂停/继续，**F9** 停录，**F10** 停录并保存；**F12** 停录。倒计时中按 F9 可立即开始。
5. 停录后进入“时间轴与编辑”，调整名称并检查、编辑，最后保存。

录制仅在明确点击开始后安装监听，停止后卸载。失焦或鼠标拖出客户区会暂停，不会自动继续；回到游戏后按 F8。暂停和停止会在数据中补齐键鼠释放，不向游戏额外发送输入。窗口关闭、身份或尺寸改变会停止并保留内容。

支持键盘长按、组合操作、左/右/中键及拖拽、滚轮和阶段标记。鼠标悬停不会持续记录。录制格式使用短边720坐标，窗口尺寸和布局仍应保持稳定。

## 编辑

在脚本库选择文件后，点击“打开时间轴编辑”或切换子标签。

- 点击时间块或操作列表，在右侧修改开始时间、按住时长、按键、鼠标坐标等，点击“应用操作”。修改只作用于所选操作。
- 拖动时间块移动操作，拖动边缘改变时长；默认吸附10毫秒，Alt临时关闭。Ctrl+滚轮缩放，也可使用“全览”。
- 时间轴占据编辑页主要区域，右侧参数区可拖动分隔条调整宽度。“专注时间轴”隐藏参数区和操作列表；“返回参数区”恢复。操作列表默认折叠，需要时展开。
- 轨道默认加高，可用“轨道＋/−”或 Shift+滚轮调整，方便点选和拖动短操作。
- “新增操作”可以添加按键长按、鼠标点击、文本、移动、滚轮或标记。键鼠按下与释放成对处理。
- “定位”只移动查看位置，不发送游戏输入。“在此拆分”要求切点处所有键鼠都已释放，并且前后都有动作；生成两个新文件，保留原脚本。
- 缩短或删除操作保留总时长；延长至末尾外才增加时长。拖拽修改会同时调整轨迹，不明确的多按钮共享轨迹会拒绝修改。
- 参数尚未应用、脚本尚未保存时，切换和关闭会提示处理。保存失败或文件被外部修改时保留草稿，不覆盖外部版本。
- 撤销重做共保留最多100个状态，并受历史内存预算限制；较大录制可保留的历史更少。

旧录制的孤立释放、缺失释放和未知动作会显示诊断。“补齐缺失释放”只修复缺少的释放；其它问题需要编辑或删除对应操作。未知字段在导入编辑中保留。

## 用于任务回放

保存后，在“脚本库与录制”点击“设为通用回放”。普通副本任务的“回放文件”选择 **“（脚本工具所选）”**，运行时会读取该选择，无需重启前端。尚未选择时兼容地使用最新录制；已选文件丢失时明确停止，不擅自更换。

“（最新录制）”、手动选文件和原有指定文件方式继续可用。原任务默认由项目处理进出副本，战斗录制无需包含这些操作。

源工程的带坐标滚轮与当前后台输入语义不同：可以导入、查看和编辑，但真实回放会明确拒绝这类动作；普通旧版滚轮继续按原方式执行。

## 守卫宝烛原生任务

“悬赏（守卫宝烛）”直接使用本工程的任务队列、Pipeline、OCR、控制器和 `battle_play`。任务及恢复流程无需原工程目录、原编译器、旧导航执行器、独立模型或任务脚本快照。

1. 先在游戏内手动接取“守卫宝烛”。任务不会点击“揭榜”、付费重试或新建角色。
2. 在脚本库打开并保存所需录制，点击“绑定守卫宝烛”。页面会显示绑定文件。任务默认使用该绑定，也可在任务选项中选择“脚本工具当前选择”。这两种来源都要求明确、有效的已保存文件，缺少选择时直接停止。
3. 根据录制内容选择“包含返回地图”或“仅战斗，由任务退关”。完整返回录制不会再次执行退出；仅战斗录制由 Pipeline 打开设置并返回地图。
4. 用前端的“重复次数”设置轮数，首次使用1轮。每轮核对目标与同一卡片“守卫”按钮，连续两次确认场内就绪后才回放；返回画面也须复核后才计次。未接任务、错误卡片、未知页面或验证码会停止。

任务绑定保存在 `recordings/.bindings.json`，只记录库内文件名。编辑保存仍写同一文件，下一轮会读取新版；当前轮及其恢复重试固定首次准备时的文件版本，中途外部改写会停止该轮。另存为新文件不会自动改绑，请再次点击绑定。使用短边720的录制与相同游戏布局；原尺寸数据须先通过导入转换，不能仅修改 `base` 数字。

### 自动恢复

在任务选项中将“自动恢复”设为“启用”，填写**当前目标窗口所属进程的游戏.EXE完整路径**，选择恢复后的已有存档1～4和每轮最多恢复次数1～3。默认关闭；程序路径与所选游戏进程不一致时不会启动恢复。启动器与游戏分属不同进程时，需要配置游戏本体。

恢复只针对连续三帧确认的近纯白故障或已核验的目标窗口丢失。前端先停止原生输入及 Agent，再只重启所选游戏进程；按当前控制器规则查找唯一新窗口、重连、识别登录及指定已有存档，确认回到游戏后重试原轮。恢复重试不增加完成次数，成功一轮后下一轮重新取得恢复预算。其它运行实例共用该进程、窗口不唯一、空存档、验证码、未知页面、脚本变化或取消均会停止。

框架按用户选择的控制器发送输入，不强制使用旧工程的前台 Seize 模式。后台按键与具体游戏客户端是否兼容、真实进出关及重启效果仍需在用户环境验收；开发测试使用静态截图、内存控制器和模拟生命周期，不会重启用户游戏。

更新本地运行目录时，关闭前端后运行 `python tools/sync_native_candle.py --apply`，再用 `tools/build_frontend.ps1 -Install` 安装前端。同步工具默认只预览；应用时备份相关文件，并保留其它任务、控制器、OCR、个人录制及已有原生选项。新任务初始重复次数为1，恢复默认关闭。

## 验证范围

录制状态机、格式转换、配对编辑、拖拽、安全拆分、原子保存、恢复草稿、运行时选脚本及回放清理均有隔离测试。前端通过固定版本原生构建；实机录制和实际副本效果需要在用户游戏环境中验收。

## 批量导入旧录制

批量导入工具只读取 ZaoMengScript 的 `data/scripts/*.json`，调用本工程的录制模型转换格式。它不读取任务队列、不导入原工程 Python 代码，也不依赖原 Qt 界面、OCR 模型或运行环境。只需保留原格式录制及其 `data/scripts` 目录结构。

```powershell
# 预检录制；去掉 --dry-run 后写入当前工程脚本库。
python tools/migrate_zaomeng_scripts.py --source F:/ZaoMengScript --target . --dry-run
python tools/migrate_zaomeng_scripts.py --source F:/ZaoMengScript --target .
```

录制保存在 `recordings/`，可在“脚本库与录制”刷新查看、进入时间轴编辑。导入以源 ID 和文件哈希识别版本，重复执行复用已有文件；已编辑的目标录制保留，新源版本另存。导入不会设置全局任务回放文件。

导入清单位于 `.local-migrations/zaomeng/scripts.json`，与个人录制一起由 Git 忽略。导入后的编辑和回放使用本工程的录制格式、脚本库及回放引擎。该工具只转换录制数据，不创建任务或替换任务流程。
